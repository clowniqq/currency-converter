# Currency Converter (Loan Calculator)

## Что это за проект?

**Currency Converter** - десктопное приложение для расчёта кредита и конвертации
ежемесячного платежа из рублей в выбранную валюту по актуальному курсу ЦБ РФ.

Пользователь вводит:
- сумму кредита в рублях,
- срок кредита в месяцах,
- годовую процентную ставку.

Приложение рассчитывает:
- ежемесячный платёж,
- общую сумму всех платежей,
- начисленные проценты (переплату).

Дополнительно можно выбрать целевую валюту (USD, EUR, CNY и другие) — приложение
конвертирует ежемесячный платёж по курсу, полученному через API ЦБ РФ и сохранённому
в локальной базе данных SQLite.

## Технологии

- **Python 3.11+**
- **tkinter** - графический интерфейс
- **SQLite** (модуль `sqlite3`) - хранение курсов валют
- **requests** — HTTP-запросы к API ЦБ РФ
- **API ЦБ РФ** — источник актуальных курсов: https://www.cbr-xml-daily.ru/daily_json.js
- **pytest** — тестирование
- **Black** — форматирование кода
- **GitHub Actions** — CI/CD (линтер + тесты)
